# 🛍️ E-Commerce (Laravel)

A full-featured Laravel e-commerce store with product catalog, cart, checkout, order management, authentication, and an admin panel — built with Blade templates, Tailwind CSS, and Vite.

## ✨ Features

- 🔐 Authentication with Laravel Breeze / Sanctum
- 🛍️ Product catalog with categories and filters
- 🛒 Shopping cart and checkout
- 📦 Order management (customer and admin views)
- 🔧 Admin panel for products, categories, and orders
- ⚡ Vite asset bundling with Tailwind CSS

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | Laravel 10+ |
| Frontend | Blade, Tailwind CSS, Vite |
| Language | PHP 8.1+ |
| Database | MySQL |

## 🚀 Getting Started

```bash
git clone https://github.com/AbanobGeorgeSamir/Ecommerce-Laravel.git
cd Ecommerce-Laravel

cp .env.example .env
composer install
npm install

php artisan key:generate
php artisan migrate --seed
npm run dev
php artisan serve
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
